# Draft App Store metadata

Name: RedactLeaf: PDF & Photo

Working name only; not yet reserved in App Store Connect.

Subtitle: Review, redact and share files

Description:

Prepare a clean copy of your documents before sending them. Import images or
PDF pages, cover selected areas, review suggested text matches, and inspect
the result before sharing. Your original files remain unchanged.

RedactLeaf works locally without an account. It exports freshly rendered PDF,
PNG or JPEG copies. PDF copies are image-only: selectable text, interactive
forms and the source accessibility structure are not retained. OCR suggestions
can miss information. Always review every page before sending it.

The free version supports complete workflows with up to three pages.
RedactLeaf Pro is a one-time purchase for larger packets, up to 30 pages
subject to the workspace pixel budget.
Restore Purchases restores Pro access; it does not restore documents.

Keywords draft: redact,document,pdf,privacy,copy,metadata,photo,batch,offline

Support URL and privacy URL: use public repository documentation once the
Terraform-managed repository exists. No unregistered domain or email is claimed.

Review notes: use the built-in labelled synthetic demo. Import a synthetic PDF,
add a mask, inspect every page in the export preview, export a raster copy.
The development StoreKit configuration is for local testing only and is not
included in the Release app. Configure the actual
product in App Store Connect before submission; do not submit a paywall with
an unavailable product as a production release.

Screenshots: capture only the synthetic demo and artificial fixture documents.
No competitor assets, home plans or personal documents are permitted.
