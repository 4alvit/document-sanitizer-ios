# Security

CleanSend creates new raster copies of documents. It does not guarantee that
every piece of personal information has been detected. OCR is an optional
suggestion mechanism and requires human review. Exporting an image-only PDF
removes selectable text and the source's accessibility structure.

Never include private documents, screenshots, names, identifiers, receipts or
keys in public issues. Reproduce problems with synthetic files. Use GitHub
private vulnerability reporting when it is enabled for this repository. If it
is unavailable, open a public issue asking for a private reporting channel
without including vulnerability details or private content.

Supported security scope: current prerelease source and release artifacts.
Report the exact commit/version, OS version, input container structure using
synthetic data, reproduction steps and observed output. No bug bounty is offered.

See docs/THREAT-MODEL.md for the security boundaries and acceptance checks.
